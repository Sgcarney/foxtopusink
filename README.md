# foxtopus.ink

Static site for foxtopus.ink, served by Cloudflare Pages. Every folder's `index.html` is one page (/podcasts, /books, /foxtoshop, /the-syndicate, /blood-vines, /privacy-policy). `_redirects` forwards retired Squarespace addresses. No build step: the output directory is the repository root.
Unknown addresses return a real 404 page (`404.html`).
